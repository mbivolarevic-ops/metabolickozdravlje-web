# Metaboličko zdravlje
Zvanični repozitorijum za razvoj sajta metabolickozdravlje.rs.

## Cilj projekta
Metabolickozdravlje.rs je nezavisna edukativna platforma namenjena:
- izgradnji SEO autoriteta u oblasti metaboličkog zdravlja;
- objavljivanju stručno utemeljenih edukativnih sadržaja;
- prikupljanju leadova kroz besplatne vodiče;
- razvoju FAQ baze;
- budućem razvoju edukativnog kviza i sistema za trijažu;
- transparentnim referral linkovima ka povezanim projektima.
