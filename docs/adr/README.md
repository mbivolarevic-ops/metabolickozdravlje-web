# Architecture Decision Records (ADR)
 
Ovaj folder sadrži sve važne tehničke i strateške odluke projekta.
 
Svaka odluka dobija svoj poseban dokument.
 
Primeri:
 
- ADR-001 – Izbor Next.js
- ADR-002 – Izbor Sanity CMS
- ADR-003 – Hostinger Deployment
- ADR-004 – SEO arhitektura
- ADR-005 – GitHub workflow
 
Cilj ADR sistema je da svaka važna odluka bude dokumentovana zajedno sa razlozima zbog kojih je doneta.
